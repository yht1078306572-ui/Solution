## 功能特性

- **8 类场景**：机器人定位、无人机定位、影视动画动捕、具身智能数据采集、虚拟仿真/VR 大空间、XR/VP 虚拟拍摄、特殊定制化项目、水下动捕
- **三档详略**：基础版 / 标准版 / 深度版（章节结构随场景差异化）
- **自动选型**：相机按场地尺寸+标记点类型做识别距离校核并自动升档；数量按部署规则计算，高度 >6m 自动两层
- **交换机选型**：口数+功率+供电等级三重校核（K 系列强制 PoE++ 802.3bt，其余 PoE+，工业场景优先工业级机型）
- **同步机选型**：按场景自动匹配 CMLOCK / CMLOCK mini（水下强制 CMLOCK）
- **水下清单**：U 系列自动配接入盒（3 台/盒）、防水电缆、水下固定套件、蓝光标记点
- **集成产品章**：每场景配“动捕+被测对象”集成产品与应用场景实拍图
- **报告内容**：部署俯视图/立面图、原理图、流程图、设备清单（BOM）、产品配图、附录

# CMSolution 使用说明

## 一、软件简介

CMSolution 是青瞳视觉内部使用的动捕方案自动生成工具。在网页表单中填写客户信息、方案类型、场地尺寸与相机配置，一键生成完整的 Word 技术方案（含部署俯视图/立面图、原理图、流程图、设备清单与产品配图），支持机器人定位、无人机、影视动捕、具身智能、VR 大空间、XR/VP 虚拟拍摄、特殊定制化项目、水下动捕共 8 类场景，以及基础版 / 标准版 / 深度版三档详略。

## 二、启动方式

**桌面版（推荐）**
- 双击软件目录下的 CMSolution.exe（Release 下载）或 CMSolution.bat（源码），自动弹出独立窗口；
- 窗口关闭即退出，不影响已生成的方案文件。

**网页版（局域网共用）**
- 运行 app.py 启动后，本机浏览器访问 http://127.0.0.1:5099；
- 同一局域网的其他电脑可访问 http://<本机IP>:5099 共同使用。

## 三、三步生成方案

1. **第 1 步**：填写“客户与方案”——客户名称（必填）、方案类型（必填）、被测对象、相机型号；
2. **第 2 步**：填写“场地尺寸”——长/宽/高（必填）与布置层数，并按所选场景填写专属选项（如追踪目标数量、人数等）；
3. **第 3 步**：在“通用选项”选择标记点类型（必选）、同步机、软件与详略程度，点击“生成方案 Word”。

生成完成后点击“查看报告”直接用 Word/WPS 打开，或“打开文件夹”进入输出目录。所有方案保存在软件目录 output 文件夹内，按“客户名-方案类型-随机码.docx”命名。

## 四、表单字段说明

| 字段 | 说明 |
| --- | --- |
| 方案类型 | 8 类场景必选，决定报告章节结构、默认相机/软件与部署规则 |
| 相机型号（主） | 默认“自动推荐”：按场地尺寸+标记点类型自动选型并给出选型说明；手动选择时下方实时提示距离是否满足（绿✓/黄△/红⚠） |
| 相机数量模式 | 自动=按部署规则计算；手动=直接指定数量，机位按几何均布 |
| 混用相机型号 | 可选第二型号，机位自动交错排布；数量缺省按总量 40% 拨出 |
| 标记点类型 | 必选：被动反光点 / 主动光标记体 / 主被动混用；决定识别距离校核口径（混用按被动从严）与标记点清单 |
| 同步机 | 自动推荐=按场景默认（虚拍/影视/定制/水下→CMLOCK，其余→CMLOCK mini）；也可手动指定或不配置 |
| 布置层数 | 自动=场地高度＞6m 时两层立体部署（相机数量成倍）；可手动指定 1-3 层；水下场景自带双层，不受此项影响 |
| 方案详略程度 | 基础版（核心章节）/ 标准版（+配图与专项章）/ 深度版（+行业分析、产品详述、SOP、培训、附录 A-F） |

## 五、内置自动规则速查

以下规则由引擎自动执行，生成报告时会将关键判断写入正文（如“相机自动选型说明”），无需人工核算：

| 规则 | 内容 |
| --- | --- |
| 相机选型校核 | 每台相机须覆盖场地中心：识别距离 ≥ √((长/2)²+(宽/2)²+高²)；自动推荐不足时自动升档最经济型号，全部不足时告警 |
| 距离余量提示 | 识别距离余量＜20% 时在报告中给出升档建议 |
| 相机数量 | 按场景部署规则计算（环绕间距/网格间距），叠加遮挡冗余；高度＞6m 自动两层，数量成倍 |
| 交换机选型 | 口数+功率+供电等级三重校核；K 系列相机强制 PoE++（802.3bt），其余 PoE+；机器人/定制场景优先工业级机型；单台不足自动多台分区接入 |
| 同步机选型 | 虚拍 Genlock/影视 Timecode/定制/水下→CMLOCK；单路通用同步场景→CMLOCK mini；水下强制 CMLOCK |
| 水下清单 | U 系列相机自动配：接入盒（每 3 台 1 盒）、防水电缆（1 根/台）、水下固定套件、蓝光 450nm 标记点与校准套件 |
| 网线数量 | 相机+参考相机+服务器+同步机+交换机，另备 2 根 |

## 六、常见问题

- **目录页码不显示？** 报告目录为 Word 引用目录，打开文档时选择“是”更新域，或全选后按 F9 刷新；
- **想改某个指标或段落？** 直接在 Word 中编辑即可，目录按 F9 重新生成；
- **相机产品图缺失？** 确认软件目录 assets 文件夹完整，缺失图片会自动跳过不影响生成；
- **生成失败/按钮无响应？** 先关闭所有正在占用 output 目录中文件的 Word 窗口再重试；仍失败请联系方案工具维护同事并附上表单填写内容；
- **需要报价？** 清单不含价格，报价请走公司商务流程。
