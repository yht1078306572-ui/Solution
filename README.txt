CMSolution · 青瞳动捕方案生成器
================================

【运行方法】
双击 CMSolution.exe 即可，无需安装任何环境。

【系统要求】
Windows 10 / 11（系统自带 WebView2 运行时，一般无需额外安装）。
若双击后窗口无法显示，请安装 WebView2：
https://developer.microsoft.com/microsoft-edge/webview2/

【首次启动】
Windows 可能弹出 SmartScreen 蓝色提示（未签名软件的正常现象），
点击"更多信息"→"仍要运行"即可。

【生成的文件】
生成的 Word 方案保存在本程序同级目录的 output 文件夹中。

【注意】
请勿单独移动 CMSolution.exe 到其他位置——exe 必须与 _internal
文件夹保持同级。要拷贝到桌面，请创建快捷方式。
